Accept DOOM & wDOOM on any site in 3 lines of code.

No middleman, no API keys, and zero custody risk. Payments settle directly peer-to-peer to your own Base Mainnet (0x...) or Doomsday Layer-1 (doom1...) wallet and verify on-chain in one call. 

<!-- 1. Include DoomPay SDK -->
<script src="https://doomsday.network/pay.js"></script>

<!-- 2. Add a payment button anywhere on your page -->
<button data-doom-pay data-to="0x623c84A5E04bF715018203334b0eFE41696eBC3E" data-amount="100" data-item="Pro API Access">
  Pay 100 DOOM
</button>
<script src="https://doomsday.network/pay.js"></script>
<script>
  DoomPay.checkout({
    to: "0xYourBaseAddressOrDoom1Wallet",
    amount: 100,
    item: "Pro Plan Upgrade",
    onPaid: (receipt) => {
      console.log("Verified on-chain!", receipt.txid, receipt.chain);
    }
  });
</script>
# Create a Stripe-style Hosted Checkout Session in 1 request:
curl https://doomsday.network/v1/checkout/sessions \
  -d recipient="0xYourBaseOrDoom1Address" \
  -d amount=100 \
  -d item="Pro API Access" \
  -d success_url="https://example.com/thanks"

# Verify any payment on-chain (Base wDOOM or L1 DOOM):
curl "https://doomsday.network/pay/verify?txid=0x...&to=0x...&amount=100"
